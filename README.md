# 등록서류 작성 도우미

화평법 등록신청자료의 **국문요약서 / 생략사유서 / 면제사유서**를 업로드한 자료(국가·국제기구 평가보고서, 논문, 시험보고서 PDF)로부터 자동 작성하고, 증빙자료(표지 + 근거 쪽)를 PDF로 발췌해 주는 웹페이지입니다.

## 사용 방법
1. 페이지 접속 → **AI 연결 방식** 선택
   - **Anthropic API**: API 키 입력, 자동 작성(유료)
   - **Claude 앱(구독)**: 요청문 복사 → claude.ai에 붙여넣기 → 답변 붙여넣기 → 적용 (추가 비용 없음)
   - **Google Gemini(무료)**: Gemini API 키 입력, 자동 작성(하루 사용량 제한, 무료분은 입력 내용이 구글 제품 개선에 쓰일 수 있음)
2. 화학물질명·CAS No.·**톤수범주** 입력 → 톤수에 맞는 시험항목이 물리화학/인체/환경 패널에 표시됨
3. 항목마다 **국문요약서 / 면제사유서 / 생략사유서** 중 하나 선택 (다시 누르면 해제, '–'는 양식 없음)
4. 자료 파일(PDF·워드 .docx·엑셀 .xlsx·파워포인트 .pptx)을 업로드 박스에 끌어다 놓기 (여러 개 가능)
5. **등록서류 작성** 클릭 → 항목별로 결과 확인·수정
6. **전체 다운로드(ZIP)**: 분야별 엑셀(작성한 시트만 표시) + 항목별 증빙자료(PDF는 표지 + 근거 쪽 발췌, 워드·엑셀·PPT는 원본 + 인용 위치 안내). 항목별 개별 다운로드도 가능

> AI가 작성한 내용은 반드시 원문과 대조해 검토하세요.

## 구성
| 경로 | 내용 |
|---|---|
| `index.html`, `style.css`, `app.js` | 화면과 동작 |
| `office-text.js` | 워드·엑셀·파워포인트 텍스트 추출 |
| `xlsx-fill.js` | 엑셀 양식의 서식을 유지한 채 셀 값만 채우는 모듈 |
| `templates/` | 양식 ver.1 (phys=물화, human=인체, env=환경) |
| `config/templates.json` | 시트별 입력칸(셀 주소·항목명·드롭다운 선택지·작성예시) |
| `vendor/` | JSZip, pdf-lib, pdf.js (외부 CDN 없이 동작) |
| `tools/` | 양식 수정/매핑 생성 스크립트(Python) |

## 양식을 바꿨을 때
1. `templates/`의 해당 파일을 새 양식으로 교체 (파일명 phys.xlsx / human.xlsx / env.xlsx 유지)
2. 시트를 추가·이름 변경했다면 `tools/build_config.py`의 `ITEMS` 목록 수정
3. `python3 tools/build_config.py` 실행 → `config/templates.json` 갱신 후 커밋

## 참고
- API 키는 브라우저에서 해당 AI 회사(Anthropic/Google)로만 직접 전송됩니다.
- 공개(Public) 저장소로 만들면 `templates/` 양식 파일도 공개됩니다.
- 워드·엑셀·파워포인트는 글자만 읽습니다(그림·스캔 이미지는 못 읽음). 예전 형식(.doc/.xls/.ppt/.hwp)은 새 형식이나 PDF로 저장해 올려야 합니다.
- 스캔본 PDF는 100쪽·30MB 이하만 처리됩니다. 텍스트 PDF는 분량이 많으면 관련도 높은 쪽만 골라 보냅니다.
